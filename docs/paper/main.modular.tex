\chapter*{초록 (Abstract)}
\addcontentsline{toc}{chapter}{초록 (Abstract)}
본 문서는 TA-BRPL(Trust-Aware BRPL)의 개발 전 주기(v1--v13.12)를 코드/정책/실험 단위로 통합 정리한 학술 보고서 초안이다.
핵심 연구 질문은 ``trust를 넣으면 왜 항상 더 안전해지지 않는가''이며, 이에 대해 (i) 신뢰 모델 설계, (ii) admission/retention/eviction 정책 연결, (iii) 토폴로지 일반화 실패 원인을 계층적으로 분석했다.

고정 토폴로지(full40)에서 최종 후보 v13.12는 BRPL 대비 공격자 의존 지표(att\_share, hit\_ratio) 개선을 재현했으나, 랜덤 토폴로지 메인실험(75 topology pairs, 750 runs)에서는 overall 기준 $\Delta$att\_share=+0.0058, $\Delta$hit\_ratio=+0.0087로 일관 우위를 재현하지 못했다.
본 결과는 ``메커니즘 자체의 무효''가 아니라 ``일반화 과정의 선택 편향(selection bias)과 정책-지형 상호작용''을 시사한다.

본 보고서는 최종 v 파라미터, 빌드 프로파일, 수식 기반 모델링, 버전별 정량 갭, 자동 생성 figure 42종을 포함한 재현 가능한 형태로 작성되었으며, 후속 연구의 직접 실행 기준(재현 명령/산출물 경로)까지 명시한다.

\chapter{서론 (Introduction)}
\section{문제 배경}
LLN/WSN 라우팅 보안에서 sinkhole류 공격은 단순 drop 이전에 route capture를 통해 의사결정 권한을 장악한다.
따라서 보안 평가는 PDR 단일 지표로 충분하지 않다.
본 연구는 ``데이터를 더 많이 보낸다''보다 ``공격자에게 네트워크 제어권을 덜 넘긴다''를 1차 목표로 둔다.

\section{연구 질문}
본 프로젝트의 핵심 질문은 다음과 같다.
\begin{itemize}
  \item Q1: Trust model($T_{fwd}, T_{ctrl}, T_{hon}$)을 BRPL parent 선택에 결합하면 attacker isolation이 향상되는가?
  \item Q2: 향상이 발생한다면 churn 비용은 어떤 수준에서 bounded 가능한가?
  \item Q3: 고정 토폴로지에서의 개선이 랜덤 토폴로지 분포로 일반화되는가?
\end{itemize}

\section{핵심 기여와 현재 상태}
\begin{itemize}
  \item 기여 1: TA-BRPL trust sensing과 decision policy를 분리(soft suspicion vs hard evidence)하는 구현 구조 확립.
  \item 기여 2: v1--v13.12의 실패/개선 패턴을 정량 지표($\Delta$att, $\Delta$hit, $\Delta$churn, $\Delta$PDR)로 추적 가능하게 정리.
  \item 기여 3: 고정 토폴로지(full40)에서 isolation 우위 재현(v13.8, v13.12).
  \item 현재 한계: 랜덤 토폴로지 메인실험에서는 overall 일관 우위 미달.
\end{itemize}

\chapter{TA-BRPL 모델링 및 알고리즘 설계}
\section{Trust 모델}
TA-BRPL은 이웃 $j$에 대해 세 축의 trust 관측값을 유지한다.
\begin{align}
T_{fwd}(i,j) &: \text{forwarding evidence 기반 신뢰} \\
T_{ctrl}(i,j) &: \text{control-plane(rank/DIO/version) 일관성} \\
T_{hon}(i,j) &: \text{queue/behavior honesty}
\end{align}

집계 trust는 가중 기하평균으로 계산한다.
\begin{equation}
T_{agg}(i,j)=T_{fwd}^{w_{fwd}}\cdot T_{ctrl}^{w_{ctrl}}\cdot T_{hon}^{w_{hon}}
\end{equation}

시간 업데이트는 비대칭 EWMA를 사용한다.
\begin{equation}
T(t+1)=\lambda T(t)+(1-\lambda)\tilde{T}(t),\quad
\lambda=\begin{cases}
\lambda_{normal}, & \text{상승/완만 변화}\\
\lambda_{decrease}, & \text{하락 시}
\end{cases}
\end{equation}

\section{의사결정 계층}
정책 계층은 ``의심 기반 soft penalty''와 ``증거 기반 hard exclusion''으로 분리된다.
\begin{itemize}
  \item Soft layer: admission/switch ranking에서 penalty 또는 margin 부여
  \item Hard layer: validation/review score 누적 기반 차단(blacklist, severe block)
\end{itemize}

\section{핵심 병목: 관측-결정 연결 품질}
시행착오의 핵심 교훈은 trust 관측값 자체보다 \textbf{관측값을 switch policy로 연결하는 방식}이 성능을 좌우한다는 점이다.
특히 $T_{fwd}$의 attribution bias(공격자 drop이 상류 relay까지 오염)와 과도한 escape 활성화는 churn cascade를 유발했다.

\begin{itemize}
  \item v1/v2: trust 도입 직후 churn 폭증과 isolation 실패
  \item v3/v4: admission 중심 안정화로 부분 회복
  \item v5: escape 재활성화로 churn 재폭증
  \item v6: conditional eviction 과보수(발동 부족)
  \item v8: $T_{fwd}$ attribution bias 진단(오탐 cascade)
\end{itemize}

v13.12에서 escape cooldown 확장(120$\rightarrow$360s)으로 BOTTLE churn을 추가 완화했다.

\chapter{논의 (Discussion)}
\section{왜 trust를 넣었는데 BRPL보다 나빠질 수 있는가}
현재 데이터가 지지하는 설명은 다음과 같다.
\begin{enumerate}
  \item 관측 신호(특히 echo 기반 $T_{fwd}$)와 원인 노드 attribution이 완전히 일치하지 않는다.
  \item admission/escape/guard의 상호작용이 토폴로지 다양성에서 동일하게 작동하지 않는다.
  \item 고정 토폴로지에서 유효했던 margin/cooldown 조합이 랜덤 분포에서는 selection bias를 유발할 수 있다.
\end{enumerate}

\section{현재 결과의 학술적 포지셔닝}
객관적으로 본 문서의 strongest claim은 다음이다.
\begin{itemize}
  \item ``v1--v13.12 progression에서 정책 실패 메커니즘을 재현 가능하게 분해했다.''
  \item ``full40에서 isolation 우위를 만들고 churn 완화까지 일부 달성했다.''
\end{itemize}

반면 아직 조심해야 할 claim은 다음이다.
\begin{itemize}
  \item ``랜덤 토폴로지 전반의 일관 우위'' (현 시점 데이터로는 미충족)
\end{itemize}

\section{다음 단계}
\begin{enumerate}
  \item scenario-aware random matrix(SINK\_ONLY/SINK\_DROP50)를 메인 파이프라인에 완전 복구
  \item topology-conditioned candidate ordering bias 분석(특히 medium/dense)
  \item 동일 통계 단위(topology-paired)로 v13.12 이후 미세 개선 재검증
\end{enumerate}

\chapter{결론 (Conclusion)}
TA-BRPL 연구는 ``trust를 더 세게 넣으면 좋아진다''는 단순 명제를 반박하고,
``trust sensing--decision coupling 품질''이 보안 라우팅 성능을 좌우함을 보여주었다.

최종 후보 v13.12는 고정 토폴로지에서 의미 있는 isolation 성과를 확보했지만,
랜덤 토폴로지 메인실험에서는 일관 우위를 재현하지 못했다.
따라서 본 결과는 종료점이 아니라, SCI급 일반화 주장을 위해 반드시 필요한 중간 검증 기반으로 해석된다.
