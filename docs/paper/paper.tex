\begin{abstract}
저전력 손실 네트워크(LLN)에서 sinkhole 계열 공격은 부모 선택을 왜곡하여 공격자 경유 비율을 높이고,
결과적으로 전달 성능 저하와 경로 불안정을 유발한다.
본 논문은 BRPL 기반 trust-aware 라우팅(TA-BRPL)의 현재 구현을 대상으로,
신규 부모 채택(admission) 경계값 조정이 성능에 미치는 영향을 실험적으로 분석한다.
핵심은 구조 재설계가 아니라 단일 전역 파라미터(\texttt{TA\_TRUST\_TAU\_JOIN})의 조정이다.
총 40-run(2 topology $\times$ 2 scenario $\times$ 2 protocol $\times$ 5 seeds) 실험에서,
기준선(v3, tau\_join=520) 대비 tau\_join=510은
TA-BRPL-BRPL 평균 격차를
$\Delta$PDR\_dur -0.0343$\rightarrow$-0.0318,
$\Delta$att\_share +0.0035$\rightarrow$-0.0029,
$\Delta$hit\_ratio +0.0324$\rightarrow$+0.0279,
$\Delta$churn +0.69$\rightarrow$+0.62로 개선했다.
즉, 절대 우위는 아직 달성하지 못했지만,
admission 경계 보정만으로 공격자 의존성과 경로 불안정 사이의 trade-off를 유의미하게 완화할 수 있음을 보였다.
\end{abstract}

\noindent\textbf{Keywords:}
LLN, RPL, BRPL, TA-BRPL, Sinkhole, Admission Control, Trust-Aware Routing, Churn

\section{서론}
IoT/LLN 환경에서 라우팅 보안의 실용적 목표는 단순히 PDR 최대화가 아니라,
공격 상황에서 네트워크가 덜 붕괴되도록 만들고(attacker dependency 감소),
불안정한 부모 교체(churn)를 억제하는 것이다.
그러나 실제 구현에서는 보안 반응을 강화할수록 경로 안정성이 악화될 수 있고,
안정성을 우선할수록 공격 회피 압력이 약해지는 상충관계가 발생한다.

본 연구는 메인실험 해석의 일관성을 위해 목표 함수를 먼저 고정한다.
본 논문의 주목표는 \textbf{PDR 절대 우위}가 아니라,
\textbf{attacker isolation with bounded stability cost}이다.
즉, 공격자 의존도(att\_share, hit\_ratio/exposure)를 1순위로 개선하고,
그 비용(churn, PDR)을 허용 가능한 범위로 제한하는 설계를 목표로 한다.

\section{배경 및 문제 정의}
\subsection{현재 TA-BRPL 구현}
현재 구현은 세 가지 trust 축을 사용한다.
\begin{itemize}
  \item $T_{fwd}$: 에코 기반 포워딩 검증
  \item $T_{ctrl}$: control-plane 이상(지속 저-rank 유인 등)
  \item $T_{hon}$: congestion honesty
\end{itemize}

집계 trust는 BRPL 부모 점수에 soft penalty로 반영되며,
review/blacklist는 hard exclusion 계층으로 분리되어 있다.
정책적으로는 ``신규 후보 admission은 엄격, 현재 부모는 신중 유지''를 채택한다.

\subsection{문제점}
기준선(v3, tau\_join=520)에서 TA-BRPL과 BRPL의 평균 격차는 다음과 같다.
\begin{center}
$\Delta$PDR\_dur=-0.0343,\;
$\Delta$att\_share=+0.0035,\;
$\Delta$hit\_ratio=+0.0324,\;
$\Delta$churn=+0.69
\end{center}
즉, 공격자 의존 감소가 토폴로지 전반에서 일관되지 않았고,
경로 안정성 비용이 남아 있었다.

\section{제안: Admission 경계 단일 보정}
본 논문은 다음 제약을 둔다.
\begin{itemize}
  \item trust 모델 축 추가 없음
  \item blacklist/escape 전면 재설계 없음
  \item 전역 단일 파라미터만 조정
\end{itemize}

조정 대상은 \texttt{TA\_TRUST\_TAU\_JOIN}이며,
기준선 520 대비 500, 510을 동일 조건으로 비교하였다.

또한 원인 분석을 위해 코드에 admission 계측(\texttt{CSV,ADMISSION})을 추가하여,
후보 평가/허용/차단 사유(blacklist, trust, review, severe)를 누적 측정했다.

\section{실험 설정}
\subsection{시뮬레이션 구성}
\begin{itemize}
  \item Topology: GRID, BOTTLE
  \item Scenario: SINK\_ONLY, SINK\_DROP50
  \item Protocol: BRPL, TA-BRPL
  \item Seed: 5
  \item 총 실행: 40-run
\end{itemize}

\subsection{비교 버전}
\begin{itemize}
  \item v3(기준선): tau\_join=520
  \item tj500: tau\_join=500
  \item tj510: tau\_join=510
\end{itemize}

\subsection{평가지표}
\begin{itemize}
  \item \textbf{1순위 (Primary)}: att\_share, hit\_ratio (공격자 의존도)
  \item \textbf{2순위 (Secondary)}: churn (안정성 비용)
  \item \textbf{3순위 (Tertiary)}: PDR\_dur (공격 구간 전달률)
\end{itemize}

시나리오별 해석 규칙도 고정한다.
\begin{itemize}
  \item SINK\_ONLY: isolation 중심(att\_share, hit\_ratio) 우선 해석
  \item SINK\_DROP50: isolation과 PDR\_dur을 동등 비중으로 해석
\end{itemize}

\section{논의}
본 결과는 다음을 시사한다.
\begin{itemize}
  \item 현재 단계의 핵심 병목은 모델 축 추가가 아니라 admission 경계 보정이다.
  \item 단일 파라미터 조정만으로도 평균 격차를 줄일 수 있다.
  \item 다만 BRPL 절대 우위를 전 구간에서 확보하지는 못했으므로,
  현재 기여는 ``정책 정합성 강화 및 격차 완화''로 해석해야 한다.
\end{itemize}

\section{결론}
본 논문은 TA-BRPL의 현재 구현에서 admission 경계 단일 보정의 효과를 검증했다.
기준선(v3, tau\_join=520) 대비 tau\_join=510은
PDR, attacker dependency, churn의 평균 격차를 동시에 완화했다.
따라서 현 시점의 코드 기준 최종 설정은
\textbf{\texttt{TA\_TRUST\_TAU\_JOIN=510}}으로 채택한다.
